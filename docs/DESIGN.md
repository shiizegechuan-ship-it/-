# 夜明けの楔（Wedge of Dawn）設計書

## コンセプト
死ぬたびに夜明け前の時計塔へ戻される。一周に打てる楔は数本だけ。
**「次の周回に何を残すか」を選び**、知識と因果を積み上げて、時間を止めた師「刻守」を超える 2D 横スクロールのローグライトアクション。

- 視点：2D サイドビュー。縦の読み合い（ジャンプ・空中攻撃・頭上を取る）と「避けた／当たった」の視認性を優先。
- 主軸のシステム：**時の楔**。楔を打った対象だけが次の夜に残る。
- 補助システム（2つ）：**知識の鍵**（暗号・名前・時刻を知っていれば行動が増える）と、**刻守の記憶**（前の夜に最も使った攻撃手段への対策を1つだけ持ち込む）。

## ループの規則（プレイヤーに明示するのは1文だけ）
> 時計の印があるものは、あなたの行いでしか変わらない。印のないものは、夜ごとに揺らぐ。

| 要素 | 区分 | 決まり方 |
|---|---|---|
| 楔を打った対象 | 保持（金色） | `meta.wedges` |
| 記録帳（知識） | 保持 | `meta.knowledge` |
| 楔の枠・解放済みの系統 | 保持 | 刻守に初めて勝つ／日誌を読むと枠が増える。書庫を開けると「停滞」の系統を解放 |
| HP・強化・ゲージ | リセット（灰） | 楔を打った強化だけは残る |
| 部屋の並び・敵の編成・強化の候補・扉の報酬 | 揺らぎ | 周回シード `loopSeed()`（セーブと周回数から決まるので再現できる） |
| 因果部屋の中身 | 変化（紫） | `meta` だけから決まる（`setupForge` など） |
| 書庫の番号 | セーブ固定 | セーブを作ったときに1回だけ抽選 |
| 刻守の対策 | 変化 | `bossCounter(meta.lastLoop)`。毎周上書きされ、積み重ならない |

## 楔の対象
| 対象 | 利点 | 代償 |
|---|---|---|
| 強化（巻き戻り画面で打つ） | その強化を持ったまま夜が始まる（鍛えたⅡも維持） | 枠を1つ使う |
| 少女リラ | 次の夜も覚えている → 父の手がかり／伝言 | 真の結末に必須。枠を取り合う |
| 鍛冶屋グレン（救出後） | 入口に現れ、毎夜強化を1つⅡに鍛える | 枠を1つ使う |
| 歯車騎士の残骸（撃破後12秒以内） | 昇降機が動き、上層の書斎へ直行できる | 書庫・中層の戦闘・上層の最初の部屋を飛ばす＝強化の機会が減る。騎士の報酬（強化2つ）も無い |
| 鐘楼の歯止め | 刻守が時止めを使えない | 刻守が怒り、第2段階が 60% → 75% に早まり、技も速くなる |

## 塔の構成（1夜 ≒ 8〜12分）
- 下層・市場：入口（リラ・看板）→ 戦闘 → 戦闘 → **鍛冶場**（夜の 1:20 までに着けばグレンの救出戦。遅れると死体が残り、期限の時刻を知る）→ 戦闘
- 中層・歯車回廊：戦闘 → **歯車騎士** → **書庫**（番号扉・日誌・「停滞」の祭壇・泉）→ 戦闘
- 上層・鐘楼：戦闘 → **書斎**（番号の走り書き・泉・歯止め）→ **刻守**

戦闘部屋を出るときは扉が2つ出て、それぞれ次の部屋の報酬（強化／回復／砂時計）が見える。

## 物語の流れ（想定）
1. 1〜2夜目：操作を覚える。グレンの期限、敵の癖を知る。
2. 刻守の第3段階で「リラ……」という独白 → 少女の名前を知る。
3. 刻守を倒しても鐘が鳴って夜が戻る（偽りの勝利）。枠が+1される。
4. 書斎で番号を知る → 次の夜に書庫を開けて日誌（師の動機）を読む。枠+1。
5. リラに楔を打ち、名前で呼ぶ → 伝言「リラは覚えてる」。
6. 第3段階で伝言を伝える → 時の力を使わない「夜明けの決闘」→ 真の結末。

## 戦闘
- プレイヤーの数値は `src/config.js`（フレームデータ・速度・無敵時間）に集約。
- ジャスト回避「刹那」：被弾の直前 8F 以内に回避すると、0.25秒のスロー＋ゲージ+30。
- 敵ごとに見分けられる予備動作：錆兵＝剣を振り上げて光る、蝙蝠＝赤い軌道線、砲台＝針が12時、騎士＝盾の発光とハンマーの振り上げ、刻守＝予告の弧・照準線・着地点の影・懐中時計。
- 強化：3系統（加速・停滞・残響）各4種＋危険2種。同系統2つで「共鳴」、系統をまたぐ相乗効果は選択カードに表示する。

## 範囲外（MVP では作らない）
複数の武器・キャラクター、4層目以降、恒久的な通貨、タイルの完全自動生成、タッチ操作、音声、本番用の絵と音。
