# 夜明けの楔（Wedge of Dawn）

2D 横スクロールのローグライトアクション × タイムループ。ブラウザで動きます（HTML / Canvas / 素の JavaScript、ビルド不要）。
設計は [`../docs/DESIGN.md`](../docs/DESIGN.md) を参照してください。

## 起動方法
ES モジュールを使うため、`index.html` をファイルとして直接開くのではなく、ローカルサーバー経由で開いてください。

```sh
cd game
npx serve -l 8080 .        # または: python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

## 操作
| 操作 | キーボード | パッド（標準配置） |
|---|---|---|
| 移動 | ← → / A D | 十字キー・左スティック |
| ジャンプ（長押しで高く） | Z / Space | A |
| 攻撃（連打で3段、長押しで重撃） | X / J | X |
| 回避（無敵あり。直前で避けると「刹那」） | C / Shift / K | B |
| 時歪（秒針ゲージを消費して周囲を遅くする） | V / L | Y |
| 調べる・話す・扉に入る | ↑ / E | 十字上・RB |
| すり抜け床から降りる | ↓ + ジャンプ | |
| 記録帳 | Tab | Back |
| 中断 | Esc / P | Start |

### スマホ
タッチ操作の端末では、画面の下（横向きなら左右）に仮想スティックとボタンが出ます。メニューや強化カードは画面を直接タップして選べます（カードは2回目のタップで決定）。横向きのほうが画面が大きくなります。

## 成長と難しさ
- **強化（夜の中）**：加速・停滞・残響・危険・火力の5系統。火力系統（10種）は取るたびに Lv が上がり（最大 Lv5）、与ダメージが伸びる。
- **コンボ**：当て続けるとヒット数が加算され、1 ヒットごとに与ダメージ +1%（強化で増える）。被弾するか、しばらく当てないと途切れる。
- **会心**：会心の一撃は ×2（強化で伸びる）。
- **時の欠片と刻印（夜をまたぐ）**：敵や部屋で欠片が貯まり、巻き戻り画面の「刻印」で恒久強化（基礎攻撃・最大HP・継承枠・会心・コンボ持続・開始ゲージ・回復量・候補数）。
- **継承**：前の夜の強化を Lv ごと持ち越せる（最初は 1 個、「継承の刻印」で最大 5 個）。
- **夜の深さ**：夜を重ねるほど敵の HP と攻撃が上がり、第3夜から新しい攻撃（二段斬り・連続急降下・3方向弾・二重の衝撃波）、第6夜からさらに（突進突き・爆弾・速射・跳躍叩きつけ）。敵の種類と数も増える。

## 1ファイル版（サーバー不要）
```sh
node tools/build-single.mjs          # dist/wedge-of-dawn.html を作る（esbuild を npx で取得）
```

## テスト
```sh
cd game
npm test            # node --test：物理・戦闘・ループ状態・部屋の到達可能性・1周の通し
```

## ファイル構成
```
game/
  index.html          起動ページ
  src/
    config.js         調整用の定数（フレームデータ・速度・無敵時間）
    input.js          入力（キーボード・パッド・テスト用の再生を同じ口で扱う）
    tilemap.js        ASCII で書いた部屋と衝突判定
    player.js         プレイヤーの状態機械（移動・ジャンプ・回避・連撃・重撃・楔を打つ動作）
    enemies.js        錆兵・振り子蝙蝠・時計砲台・歯車騎士・歯車転がし・時計弓兵・刻の亡霊・鐘撞き・弾
    boss.js           刻守（3段階・時止め・刻守の記憶による対策技）
    boons.js          強化と共鳴・相乗効果
    world.js          部屋のレイアウトと周回ごとの塔の構成（揺らぎ）
    meta.js           周回をまたぐ状態（楔・知識・枠）と周回の終わりの計算（因果）
    game.js           ゲーム本体（DOM に依存しない。テストからも動く）
    render.js / ui.js 描画と HUD・メニュー・巻き戻り画面
    audio.js          WebAudio による合成効果音
    pix.js            ドット絵の描画基盤（320×180 の低解像度バッファ、点・線・円・スプライト）
    sprites.js        手描きのドット絵スプライト（味方は丸い輪郭、敵は角とトゲと赤い目）
    background.js     階層ごとの背景（視差スクロール）とタイルの手続き生成
    touch.js          スマホ用のタッチ操作
    main.js           ブラウザでの起動処理（固定 60Hz 更新）
  tests/              node:test によるテスト
```

## 素材について
絵はコードに書いたドット絵（スプライトは文字列で手描き、背景とタイルは手続き生成）で、音は WebAudio で合成しています。外部の画像・音声ファイルはありません。文字はドット文字フォント DotGothic16（Google Fonts）を使い、読み込めない場合は OS の日本語フォントで表示されます。`tools/sprites.html` を開くとスプライトの一覧（通常と影絵）を確認できます。

## セーブ
`localStorage` に自動で保存されます。タイトル画面の「はじめから」で消去できます。

## 検証状況（正直な一覧）
**確認済み（自動テスト 67 件・headless Chromium）**
- 操作：可変ジャンプ、コヨーテタイム、先行入力、回避の無敵と距離、硬直の回避キャンセル、入力遅延なし、ヒットストップ中の入力の持ち越し
- 戦闘：3段連撃のダメージ、重撃で盾を崩す、騎士の正面で弾かれる／背後なら通る、ジャスト回避の成立と不成立、強化の効果（残響・遅延＋粉砕・時歪）、弾を斬り落とせる
- ループ：楔の枠・重複・抜く、周回の終わりの保持／リセット、セーブの読み込みと破損時の扱い、刻守の記憶、偽りの勝利で枠+1、真の結末の条件
- 因果：リラ・グレン・騎士・歯止めの各楔が次の夜に正しく反映される、グレンの期限と救出戦、番号はセーブ固定
- 再現性：同じセーブ・同じ夜なら塔の構成と強化候補が一致する。戦闘部屋は夜ごとに揺らぎ、因果部屋の位置は変わらない
- 全レイアウトで敵・仕掛け・出口へジャンプで届く（進行不能なし）。扉と人物が重ならない
- 1周の通し（全部屋 → 刻守 → 鐘 → 巻き戻り → 次の夜）、真の結末までの通し、ランダム入力での耐久
- 成長：新しい敵4種が予兆のあとに攻撃する、夜の深さで敵が強くなり攻撃パターンが変わる、コンボ加算と途切れ、会心の再現性、火力強化の Lv アップ、欠片と刻印、継承の持ち越し、古いセーブの読み込み
- ブラウザ：全部屋と全画面を描画してコンソールエラーなし。実キー入力での開始・移動・攻撃・回避・溜め・中断・記録帳・扉の移動。1フレームの更新と描画は中央値 0.4ms
